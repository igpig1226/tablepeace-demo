EXPANSION MAP

面向长期协作的能力地图

以下均为规划方向，并非当前可用功能
01 / CONNECT

日历与群聊连接

在获得授权后读取空闲时段，并将最终结果带回原来的群聊。

02 / VERIFY

场地事实核验

接入营业时间与预约状态，同时保留来源和人工复核记录。

03 / OPERATE

自动提醒与截止时间

只提醒未回应的人；到期后明确展示仍未知的条件。

04 / REUSE

可复用团队模板

复用会议、活动和出行的决策结构，不复用未经许可的私人条件。

05 / REVIEW

决策轨迹与复盘

记录方案变化、人工核验和确认版本，生成可分享的过程摘要。

06 / PLATFORM

组织级权限与 API

让社团或团队接入既有工具，并配置数据保留与访问范围。

三道清晰边界

能一起去，和已经决定，是两回事。

系统只依据成员明确提交的硬性条件计算兼容性。地点是否可用需要人核实；最终承诺需要每个人明确确认。

01 · 兼容已记录条件中没有冲突。未知条件仍显示未知。
02 · 核实有人实际检查场地、营业时间或预订状态。
03 · 确认全部成员接受同一版本的具体方案。
